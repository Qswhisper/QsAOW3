# 当前验证范围

v0.1.0 发布的是已经验证的 ARM64 安装包。公开仓库提供对应适配源码及独立构建工具，不改变这个安装包的游戏行为。

| 检查 | 结果与范围 |
| --- | --- |
| 独立重建 | Windows、Python 3.11+、Java、NDK 29.0.14206865、Build Tools 36.0.0；仅使用本仓库、固定启动 APK 和工具链 |
| 原生库一致性 | 重建的 `libmain.so` 与发布包逐字节一致 |
| APK 内容一致性 | 除重新生成的签名外，重建包的全部 ZIP 文件内容与发布包一致；新开发签名不同属于预期 |
| 离线输入 | 381 项文件逐一检查大小与 SHA256；战役/合作目录的引用、校验与前置关系检查通过 |
| 应用身份 | 包名 `com.art3rts00.aow`；应用及启动入口名称 QsAOW3；没有 Android INTERNET 或 BILLING 权限 |
| 独立规则测试 | 64 项 C++ 测试在 Android x86_64 上通过，断言启用；使用合成状态和规则样本，不读取玩家档 |
| 启动与覆盖 | 干净数据断网首启原教程、原失败安装覆盖后首启、断网冷启动大厅经过原引擎验证 |
| 物理设备 | 一加 15T 启动及若干早期战役试玩正常；没有据此推断全部章节或长期稳定性 |
| 源码结构 | 本地文档链接、C++ 引用、意外密钥/二进制/个人路径检查通过 |

规则测试覆盖 AI 规划与预算、目标选择、战役目录、独立生涯、历史存档布局、损坏拒绝、余额与库存、科研/英雄/技能、正式胜负结算、重复领取和履历统计。清单见 [validation.json](../data/validation.json)。这些测试不能替代 ARM64 原引擎中场景、操作和终局的实际运行。

公开测试将历史外部样本依赖改为现场生成的合成样本，并更新了过时的奖励拒绝用例；生产运行代码没有随测试整理而改变。Linux/macOS 主机路径已实现，本次未在这两种主机执行完整构建或测试。`ci/release.yml` 是待维护者审查启用的模板，本次验证不代表 GitHub Actions 已运行。
