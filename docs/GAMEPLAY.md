# 当前玩法与单机规则

原操作、场景、目标脚本和终局继续使用原引擎。以下条目说明本地成长服务，便于理解它与纯联网原流程的差异。

## 生涯与成长

新生涯沿原初值及原教程开始，不全解锁。保留军衔、星、有效价格、卡片与前置；训练入口可提前使用。研究即时完成，仍需满足有效扣费/阶段/前置；未知混合效果整条拒绝，避免收费后只应用部分效果。

局外恢复等待、免费箱间隔、战争点日上限和每日首胜等失效计时/日历节点可零资源手动通过，保留其结构前置和一次性收据。其他有效节点不因此免费。战争点不设每日上限，也不额外补赠战争点或每日首胜奖励。

部分常规军种的未知转向成长采用明确的单机适配：列入表的节点每购一级转向 +1，同军种最多 +6；原转向为 0 的动作不启用，原字段上限仍有效，不改最高移速或猜测加速度。剩余混合研究仍可能受限。

随机英雄卡在当前阵营、同稀有度且原军衔允许的英雄中均匀选择；技能卡按原树同稀有度均匀选择。原数量和门槛保留。出战前英雄铀补到原上限，局内仍按原激活成本消耗，不额外赠电池。

## 正式与合作结算

- 新正式 1v1/2v2/3v3 的真实正常胜利：基础 2770 信用，适用原信用卡加成按开局冻结；不额外送 XP。
- 正式正常胜利的军衔星预算：`max(1, ceil((下一原门槛 - 当前原门槛) / 3))`，按开局军衔冻结；最高原军衔不继续加星。正常失败不加减星。
- 已支持合作的新局正常胜利：基础 2770 信用，按原合作信用卡加成冻结；原合作/南瓜点机制保持，不额外送军衔星或战争点。
- 训练、诊断、投降、中断、异常和旧战绩不兑现上述正式正常胜利奖励。战役继续按原最佳完成/星/奖励记录结算。

这些是单机规则，不声称恢复了原服务器的完整奖励算法。结算必须使用真实原引擎结果和一次保存/冷恢复事务。

## 箱子、委托与合同

商店免费箱首次手动领一次，之后每 3 场新的正常终局补一箱；训练、投降和中断不计。其他已接入箱组保持原数量和手动领取规则，未知奖励整箱暂缓，不能部分发奖或重抽已冻结内容。

固定委托沿原目标与公开后继，仅在条件清楚且奖励支持时根据真实记录手动领取一次。合同保留原军衔入口、目标和数量，领完后可原位继续新的真实行为循环。两排合同箱共享新领取积分，支持原顺序、超额结转和续轮。

已接常规合同在高军衔继续使用当前定义；缺少完整高军衔池时延续当前常规箱组，并在原位置说明。没有把这种延续计作补齐全部原活动内容。纯登录、广告、付费任务不加入离线循环。

纯联网社交、真实购买、签到、礼品码等未接入服务已禁用或隐藏；原界面中保留的免费领取、库存转换、研究和模式选择继续使用已实现的本地服务。
