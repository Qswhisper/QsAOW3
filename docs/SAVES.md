# 生涯与存档

应用根目录为 Android 为本包提供的外部 files 目录；原代码通过 `/sdcard/Android/data/com.art3rts00.aow/files/` 访问，在不同 Android 用户中映射各自空间。

| 文件/目录 | 用途 |
| --- | --- |
| `local-accounts.0`、`.1` | 64 字节 A/B 生涯选择器，包含 generation、当前/之前/下一个生涯身份 |
| 根目录旧生涯 | 原本地生涯 0，保持原位，不搬移旧文件 |
| `accounts/slot-<20位编号>/` | 后建独立生涯的根目录 |
| `career-f1/`、阵营根目录 | 双阵营成长各自保存，既有跨阵营金币口径由账户层处理 |
| `local-progress.0`、`.1` | 当前 v16，60280 字节，钱包/章节/研究/库存/成长收据 |
| `local-ai.0`、`.1` | 对局冻结信息和结算日志，当前线格式 136 字节 |
| `cooperative.0`、`.1` | 合作日志；线格式与运行期结构分开 |
| `battle-history/` | 原履历卡片所需的不可变比赛快照 |

布局、校验和与所有迁移版本以 `native/*_store.h` / `local_progress.h` 中的定义和 `static_assert` 为准。A/B 选择器与成长记录用 generation 和校验和选取有效新记录；损坏/写入失败不得清零生涯来“恢复”。

教程的整数 PlayerPrefs 按生涯/存储根目录隔离。生涯 0 兼容既有未加作用域的教程键，后建生涯使用独立作用域；全局音量等设置保持全局。

维护存档格式时：追加字段并显式迁移，保留旧收据语义；不能重新排列合同槽位来解释旧记录，也不能给旧战绩回补新奖励。真实战斗的日志与钱包对账只兑现一次。

`tools/inspect_save.py` 提供只读校验和/结构读取。输出属于对应玩家的本地数据，应留在 `.local` 或玩家自己的备份中，不提交仓库/Issue。升级验收使用新建测试数据；玩家当前进度仅做保护和前后对比，不用历史测试快照覆盖。
